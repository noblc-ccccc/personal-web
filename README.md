# Personal Website

这是一个最基础的个人网站模板，适合放个人简介、经历、项目成果和联系方式。

## 文件说明

- `index.html`: 网站内容结构
- `styles.css`: 网站视觉样式
- `script.js`: 简单交互逻辑
- `.gitignore`: 告诉 Git 哪些文件不需要上传

## 如何预览

直接双击 `index.html`，或在浏览器中打开它即可。

## 上传到 GitHub

在当前文件夹打开终端后，执行：

```bash
git init
git add .
git commit -m "Create personal website"
git branch -M main
git remote add origin https://github.com/你的用户名/你的仓库名.git
git push -u origin main
```

把上面的仓库地址替换成你自己的 GitHub repository 地址。
